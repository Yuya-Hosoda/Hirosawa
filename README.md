# Battery-Constrained Multi-Agent Path Finding for MoMo5

**再現対象論文**: 廣澤考冶 (2025)「Mobile Module における充電制約付きマルチエージェント経路計画手法の提案」立命館大学 卒業論文

## 概要

天井面移動ロボットMoMo5の複数台協調運用において、バッテリー残量を考慮した衝突回避・充電行動を含む経路計画システムのPython再現実装です。

## 論文との対応

本実装は論文の以下の核心的知見を再現しています：

1. **安全性保証**: Low-Level探索がバッテリー制約を満たさない経路を排除（実験1）
2. **離散化粒度の影響**: 粗すぎるSoC離散化が充電経路の探索を阻害（実験2）
3. **CS選択戦略の有効性**: Jコスト最小化がCS競合を緩和しスループット向上（実験3）
4. **Lifelong安全性**: 長時間運用でもエネルギー枯渇ゼロを維持
